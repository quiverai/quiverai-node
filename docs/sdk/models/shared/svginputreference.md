# SvgInputReference

Remote or base64-encoded SVG source to animate.


## Supported Types

### `shared.SvgInputReferenceUrl`

```typescript
const value: shared.SvgInputReferenceUrl = {
  url: "https://example.com/uploads/source.svg",
};
```

### `shared.SvgInputReferenceBase64`

```typescript
const value: shared.SvgInputReferenceBase64 = {
  base64: "PHN2Zy8+",
};
```
